# Decision notes — format

One file per decision. Filename: `YYYY-MM-short-slug.md`.

Each note answers four questions, in this order:

1. **Question** — what choice was actually being made?
2. **Evidence** — the number(s) that drove the decision (with source: which
   benchmark run, which dataset/split).
3. **Decision** — what was chosen, in one sentence.
4. **When this could flip** — the condition under which you'd revisit this.

Keep it short. This is a reference you'll reread in an interview, not an
essay. See `TEMPLATE.md` for the skeleton.
